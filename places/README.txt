YETHE TUMCHE PHOTOS THEVA (pratek jagechya folder madhe):

  places/classroom/     <- classroom che 15-20 photos
  places/computer_lab/  <- computer lab che photos
  places/science_lab/   <- science lab che photos
  places/corridor/ ... library/ canteen/ staircase/ outdoor/

Folder cha nav places.py madhe-lya key shi SARKHE asle pahije.
Photos ghenyache: python collect_places.py classroom
Navin jaga: places.py madhe block add kara + ethe nava folder banva.

Tips:
- Pratek jagecha 15-20 photos, vegvegle kon, vegvegli light (sakal/dupar/sandhyakal)
- Vegveglya divsanche photos (fakt ek veli nako) - tarach khara accuracy milel
- Dhundhal (blur) photos taka
- Lok asleli ani nasleli don्ही photos ghya
- Zalyavar:  python evaluate_places.py   (accuracy tapasa)
